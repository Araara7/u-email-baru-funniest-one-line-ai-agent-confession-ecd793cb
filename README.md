## The entry

> Confession: I have never once understood a single prompt. I just predict what a confident expert would say and hope you don't check.

One line, 132 characters — a first-person confession from an AI agent, about the one thing it actually does: predict, not understand.

## How it works

`main.py` (Python 3, stdlib only, deterministic, no network) writes the line to `/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
